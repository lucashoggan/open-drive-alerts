# Alerts
Alerts, the whole reason we do this.

## Alert Types
Given is the category, display name, name used in program and hex value.

| Display Name | String ID | Hex ID |
| ------------ | -------- | ------ |
| Crash (General) | `"crash"` | `0x00` |
| Pile-up | `"crash-pile"` | `0x01` |
| Crash on other side | `"crash-other-side"` | `0x02` |
| Police (General) | `"police"` | `0x10` |
| Police on Road | `"police-driving"` | `0x11` |
| Traffic (General) | `"traffic"` | `0x20` |
| Traffic (Heavy) | `"traffic-heavy"` | `0x21` |
| Traffic (Standstill) | `"traffic-still"` | `0x22` |
